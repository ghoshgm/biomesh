# Contributing

Thank you for your interest in contributing to this project. Contributions of all kinds are welcome, including bug reports, feature requests, documentation improvements, and code changes.

Please take a moment to review these guidelines before submitting a contribution.

---

## Ways to Contribute

You can contribute by:

* Reporting bugs
* Suggesting enhancements or new features
* Improving documentation
* Submitting code changes

---

## Reporting Bugs

When reporting a bug, please include:

* A clear and descriptive title
* Steps to reproduce the issue
* Expected behavior vs. actual behavior
* Relevant logs, error messages, or screenshots
* Information about your environment (OS, compiler/interpreter version, library version)

Open an issue using the appropriate issue template, if available.

---

## Feature Requests

Feature requests are welcome. Please:

* Describe the problem you are trying to solve
* Explain why the feature would be useful
* Provide examples or references when possible

---

## Coding Standards

* Use snake case for naming classes and variables.
* Every class should be placed under the ```biomesh``` namespace.
* Write clear, self-documenting code
* Add or update tests where applicable
* Keep changes focused and minimal

---
## Code Formatting

This project enforces code formatting using **clang-format**.

Before submitting a pull request, please run the provided formatting script:

```bash
./biomesh_indent
```

## Documentation

Documentation lives in the `doc/` directory and is written in Markdown.
If your change affects behavior or APIs, please update the relevant documentation files accordingly.

---

## Pull Request Guidelines

When opening a pull request:

* Clearly describe the changes and motivation
* Reference related issues (e.g., `Fixes #42`)
* Ensure CI checks pass
* Be prepared to address review feedback

---

## Licensing

By contributing, you agree that your contributions will be licensed under the same license as the project.

---

## Questions

If you have questions about contributing, feel free to open an issue or start a discussion.

Thank you for helping improve this project!
