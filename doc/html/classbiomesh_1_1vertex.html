double biomesh::vertex::operator() ( char  dir) const

Function to retrieve the value of coordiante. Set dir to 'x' to get the X coordiante. Set dir to 'y' to get the Y coordiante. Set dir to 'z' to get the Z coordinate.

If this function is called via vertex2D then the Z coordinate will always be 0.

If dir does not match 'x' or 'y' or 'z' then DOUBLE_MAX will be returned.

Parameters
[in]dirThe required coordinates value.
Returns
The magnitude of the desired coordinate.
