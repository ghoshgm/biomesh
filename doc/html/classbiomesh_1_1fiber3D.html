Detailed Description

Class for modelling a 3D fiber.

Muscle fiber is represented as a 1D grid. A fiber is modelled as an ordered set of cartesian coordiantes. The input is a single vertex. This initial vertex will be used to sequentially compute the next fiber vertex. The output is a set of vertices which define the fiber geometry.
