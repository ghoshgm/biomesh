Detailed Description

Class to load and preprocess vector data from a vtk file.

The input is a vtk file which encodes the vtk structured grid data structure. The vertices of the grid cells hold the vectors ( one vector per vertex ).

The class performs preprocessing of the vtk data. The processed vector field will be used for generating the 1D grids.

The output is a vtk structured grid which holds all the necessary vector data for generating muscle fibers (1D grids).

◆ operator[]()

int biomesh::vector_field::operator[] ( size_t  cell_index) const

Retrieve the cell type in the VTK structured grid.

The cells are classified as '0','1','2' cells.

'0' cell -> The cells which have all corners with no vector data. '1' cell -> The cells which have some (not all) corners with vector data. '2' cell -> The cells which have all corners with vector data.
